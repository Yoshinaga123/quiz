# Quiz Admin Web

React + TypeScript + Vite based admin console for quiz management.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
npm test
```

## Responsibility

- Quiz creation, editing, and deletion
- Admin-facing operations only
- Communicates with the shared Go API

## Workspace layout

- `../admin-web`: this application
- `../mobile`: Flutter quiz app
- `../backend`: Go API
- `../quiz.md`: shared requirements
- `../docs`: project-wide design and ADRs
