# アタックムービー制作メモ

## 目的
Jazz を BGM にした、3〜5秒の短尺映像を連結したアタックムービーを制作する。

## 使用ツール
- Google Gemini
- Google Vids

## ツール選定理由
- Gemini の動画生成は利用制限に到達しやすいため、動画パートは主に Google Vids で対応する。
- BGM、ロゴ、画像素材は Gemini または Vids で作成する。

## 構想
- 雰囲気: Jazz に合う綺麗な映像
- 尺: 1カット 3〜5秒
- 構成: 複数カットをテンポよくつなぎ、最後にロゴを表示

## 制作方法
講義動画視聴後の作戦会議で、以下の手順に決定。

1. アタックムービーの基になる BGM と、動画末尾に表示するロゴを Gemini または Vids で作成。
2. 動画のベースになる画像を作成。
3. 作成した画像をベースにして、3〜5秒程度の短い動画を複数作成。
4. 全素材をマージして一本化。

## 使用プロンプト

### 1. 音楽生成（初回）
2000年代のどこか懐かしいジャズで、ボーカル無しのきれいなピアノが程よく旋律する曲。

条件:
- OP やアタックムービーに使用できること
- エレクトロキーボードとピアノの旋律を含むこと

### 2. 音楽調整（生成後の追加指示）
ゆっくりとしたニュース番組に使用されるような曲。

### 3. 画像生成
空から見上げるような状態で、東京タワーを中心に街並みが映るようにする。
高速道路に車の光跡が残る画像にする。

綺麗な東京の夜景が見えるオフィスでミーティング

DXSでシンプルなロゴを作成して下さい。
### 4. 動画生成
Strictly faithful to the original reference material.

（元の参照素材に厳密に忠実に。）

Keep it exactly as the provided source image. No alterations to composition or lighting.

（提供された元画像と全く同じに保つこと。構図や照明の変更はなし。）

### 5. エフェクト・編集設定
- 映像1〜映像2の間、および最後のロゴ表示部分に、0.7秒のディゾルブを適用する。
- 最後は BGM を5秒かけてフェードアウトする。
- 映像的につながっている中間部分には、エフェクトを適用しない。
