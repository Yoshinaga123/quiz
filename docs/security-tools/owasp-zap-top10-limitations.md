# OWASP ZAP — OWASP Top 10 対応・限界まとめ

## 総合評価

OWASP ZAP は自動スキャンと CI/CD 連携に優れる一方、**ビジネスロジックや認可制御の評価は自動化できない**。

---

## A01: アクセス制御の不備 (Broken Access Control)

| 項目 | 内容 |
|------|------|
| **対応度** | △ 部分的 |
| **できること** | ディレクトリリスティング・強制ブラウジングで未認可パスへのアクセスを検出 |
| **できないこと** | IDOR (Insecure Direct Object Reference) の検出。ユーザ A のリソースにユーザ B がアクセスできるかは、2 ユーザの比較が必要であり ZAP の自動スキャンでは判断不能 |
| **根本的な理由** | ZAP はリクエスト・レスポンスの構造を解析するが、「このリソースが誰に属するか」という仕様を知らない |

**補完手段**: 手動テスト、または Burp Suite + Autorize 拡張

---

## A02: 暗号化の失敗 (Cryptographic Failures)

| 項目 | 内容 |
|------|------|
| **対応度** | ○ 良好 |
| **できること** | HTTP での機密情報送信の検出 / 弱い TLS バージョン・暗号スイートの検出 / Cookie の `Secure` フラグ未設定の検出 / レスポンスボディ内のクレジットカード番号・パスワードの平文露出検出 |
| **できないこと** | サーバサイドの暗号化実装の妥当性 (例: 弱い乱数生成、鍵管理の問題) の検出。これらはコードレビューや静的解析 (SAST) が必要 |
| **根本的な理由** | ZAP は通信上のデータしか観測できず、サーバ内部の暗号処理ロジックにはアクセスできない |

---

## A03: インジェクション (Injection)

| 項目 | 内容 |
|------|------|
| **対応度** | ◎ 高い |
| **できること** | SQL インジェクション (エラーベース・ブラインド・時間ベース) / XSS (反射型・格納型・DOM) / コマンドインジェクション / LDAP インジェクション / XPath インジェクション / SSTI |
| **できないこと** | **帯域外 (Out-of-Band) インジェクション**の確実な検出。DNSコールバックを必要とする Blind 系の脆弱性は ZAP の標準機能では検出精度が低い |
| **根本的な理由** | ZAP に Burp Collaborator 相当の外部コールバックサーバ機能がなく、OOB での検証が困難 |

**補完手段**: Burp Suite Professional + Collaborator

---

## A04: 安全でない設計 (Insecure Design)

| 項目 | 内容 |
|------|------|
| **対応度** | ✕ 対応不可 |
| **できること** | なし |
| **できないこと** | ビジネスロジックの欠陥 (例: クーポンの重複使用、レート制限なしの API、フローのスキップ) はすべて仕様の理解が必要なため自動検出不可 |
| **根本的な理由** | ZAP はリクエスト・レスポンスのパターンマッチングで動作しており、「本来あるべき設計」を判断するデータを持たない |

**補完手段**: 脅威モデリング・手動テスト・コードレビュー

---

## A05: セキュリティの設定ミス (Security Misconfiguration)

| 項目 | 内容 |
|------|------|
| **対応度** | ◎ 高い |
| **できること** | セキュリティヘッダ不備 (`CSP`, `HSTS`, `X-Frame-Options` など) / ディレクトリリスティング / デフォルト認証情報 / 不要な HTTP メソッド (TRACE, PUT など) / エラーページによるサーバ情報漏洩 |
| **できないこと** | クラウド・インフラ層の設定ミス (S3 バケットのパブリック公開など) / ファイアウォール設定 / OS レベルのセキュリティ設定 |
| **根本的な理由** | ZAP は Web アプリ層のみを対象としており、インフラ層には届かない |

---

## A06: 脆弱なコンポーネント (Vulnerable and Outdated Components)

| 項目 | 内容 |
|------|------|
| **対応度** | △ 部分的 |
| **できること** | HTTP レスポンスヘッダからフレームワーク・ライブラリのバージョンを取得し、既知の脆弱性情報 (CVE) と照合 |
| **できないこと** | JavaScript バンドル内の依存ライブラリのバージョン特定 / サーバサイドの全依存関係の把握 / `package.json` や `pom.xml` などのマニフェストファイルの解析 |
| **根本的な理由** | ZAP は通信の観察のみで動作し、ファイルシステムや依存関係グラフへのアクセス手段を持たない |

**補完手段**: OWASP Dependency-Check, npm audit, Snyk などの SCA ツール

---

## A07: 認証・セッション管理の失敗 (Identification and Authentication Failures)

| 項目 | 内容 |
|------|------|
| **対応度** | ○ 良好 |
| **できること** | Cookie の `HttpOnly` / `Secure` / `SameSite` フラグ不備の検出 / セッション固定化の検出 / 認証なしでアクセスできるページの検出 / ログイン後にセッション ID が変わらない問題の検出 |
| **できないこと** | セッショントークンのエントロピー (ランダム性) の統計的分析 / MFA (多要素認証) の実装品質の評価 / パスワードポリシーの適切性の判断 |
| **根本的な理由** | セッション ID の統計的分析は ZAP の標準機能に含まれない (Burp Sequencer 相当の機能がない) |

**補完手段**: Burp Suite Sequencer

---

## A08: ソフトウェアとデータの整合性の失敗 (Software and Data Integrity Failures)

| 項目 | 内容 |
|------|------|
| **対応度** | △ 部分的 |
| **できること** | `integrity` 属性のない外部スクリプト読み込み (SRI 未設定) の検出 |
| **できないこと** | CI/CD パイプライン内のサプライチェーン攻撃の検出 / 署名検証の欠如 / 依存ライブラリの改ざん検出 |
| **根本的な理由** | これらは Web アプリのレスポンスではなく、ビルド・デプロイプロセスの問題であり ZAP の検査範囲外 |

**補完手段**: CI/CD セキュリティツール (Sigstore, SLSA フレームワーク など)

---

## A09: セキュリティログ・監視の失敗 (Security Logging and Monitoring Failures)

| 項目 | 内容 |
|------|------|
| **対応度** | ✕ 対応不可 |
| **できること** | なし |
| **できないこと** | サーバサイドのログ設定・ログの網羅性・アラートの設定状況はすべてサーバ内部の問題であり ZAP では評価できない |
| **根本的な理由** | ZAP はクライアント〜サーバ間の HTTP 通信のみを観察するため、サーバ内部のログ処理にアクセスする方法がない |

**補完手段**: ログ監査ツール・SIEM / 手動でのサーバ設定レビュー

---

## A10: サーバサイドリクエストフォージェリ (SSRF)

| 項目 | 内容 |
|------|------|
| **対応度** | ○ 良好 (ただし制限あり) |
| **できること** | エラーメッセージやレスポンス差異を使った SSRF の検出 |
| **できないこと** | **Blind SSRF** の確実な検出。サーバが内部ネットワークにアクセスしてもレスポンスに何も返さない場合、ZAP は検出できない |
| **根本的な理由** | ZAP に DNS コールバック (OOB) を受け取るための外部サーバ機能がなく、Blind SSRF の証明が困難 |

**補完手段**: Burp Suite Professional + Burp Collaborator

---

## まとめ: ZAP が苦手な Top 10 カテゴリ

| カテゴリ | 理由 |
|---------|------|
| **A01 アクセス制御の不備** | IDOR など仕様依存の認可テストが自動化不可 |
| **A04 安全でない設計** | ビジネスロジックの評価は自動化不可 |
| **A08 整合性の失敗** | CI/CD・サプライチェーンは検査範囲外 |
| **A09 ログ・監視の失敗** | サーバ内部の設定は観測不可 |
| **A03 (OOB)** | Blind 系インジェクションの検出精度が低い |
| **A10 (Blind SSRF)** | OOB コールバックが必要な SSRF を検出できない |
