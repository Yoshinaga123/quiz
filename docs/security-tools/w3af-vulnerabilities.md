# w3af で検査できる脆弱性一覧

## 概要

w3af はプラグインベースのアーキテクチャで、200 以上のプラグインを組み合わせて脆弱性を検出します。プラグインは役割ごとにカテゴリ分けされています。

| プラグインカテゴリ | 役割 |
|----------------|------|
| **crawl** | URL・パラメータの探索 |
| **audit** | 脆弱性の検査 |
| **grep** | レスポンスのパッシブ解析 |
| **infrastructure** | サーバ情報の収集 |
| **auth** | 認証処理 |
| **output** | レポート出力 |

## インジェクション系

### SQL インジェクション
- エラーベース・ブラインド・時間ベース SQL インジェクション
- MySQL, PostgreSQL, MSSQL, Oracle, SQLite に対応
- **プラグイン**: `audit/sqli`, `audit/blind_sqli`
- **スキャン種別**: アクティブ

### コマンドインジェクション (OS Command Injection)
- Unix / Windows コマンドの注入
- **プラグイン**: `audit/os_commanding`
- **スキャン種別**: アクティブ

### LDAP インジェクション
- LDAP クエリへの不正な文字列注入
- **プラグイン**: `audit/ldapi`
- **スキャン種別**: アクティブ

### XPath インジェクション
- XML データを操作する XPath クエリへの注入
- **プラグイン**: `audit/xpath`
- **スキャン種別**: アクティブ

### Server-Side Template Injection (SSTI)
- テンプレートエンジンへのコード注入
- **プラグイン**: `audit/ssti`
- **スキャン種別**: アクティブ

### HTTP ヘッダインジェクション (CRLF インジェクション)
- レスポンスヘッダへの改行文字注入
- **プラグイン**: `audit/http_header_injection`
- **スキャン種別**: アクティブ

## クロスサイトスクリプティング (XSS)

### 反射型 XSS (Reflected XSS)
- URL パラメータ・フォームの入力値が即座にレスポンスに反映される
- **プラグイン**: `audit/xss`
- **スキャン種別**: アクティブ

### 格納型 XSS (Stored XSS)
- データベース等に保存されたスクリプトが後から実行される
- **プラグイン**: `audit/xss` (stored モード)
- **スキャン種別**: アクティブ

### DOM ベース XSS
- JavaScript による動的な DOM 操作を起因とする XSS
- **プラグイン**: `grep/dom_xss`
- **スキャン種別**: パッシブ (grep)

---

## ファイル・パス操作

### パストラバーサル (Directory Traversal)
- `../` を使ったサーバ上の任意ファイル読み取り
- **プラグイン**: `audit/file_read`
- **スキャン種別**: アクティブ

### ローカルファイルインクルード (LFI)
- サーバ内のファイルをインクルードさせる攻撃
- **プラグイン**: `audit/lfi`
- **スキャン種別**: アクティブ

### リモートファイルインクルード (RFI)
- 外部の悪意あるファイルをインクルードさせる攻撃
- **プラグイン**: `audit/rfi`
- **スキャン種別**: アクティブ

---

## セキュリティ設定ミス

### ディレクトリリスティング
- Web サーバのディレクトリ一覧が公開されている
- **プラグイン**: `grep/directory_listing`
- **スキャン種別**: パッシブ (grep)

### 管理画面・既知パスの露出
- `/admin`, `/phpmyadmin`, `/manager` などへのアクセス確認
- **プラグイン**: `crawl/web_spider`, `crawl/forced_browsing`
- **スキャン種別**: アクティブ

### バックアップ・一時ファイルの露出
- `.bak`, `.swp`, `~`, `.old` などの拡張子のファイル
- **プラグイン**: `grep/backup_file_name`
- **スキャン種別**: パッシブ (grep)

### デバッグ機能・エラーメッセージの漏洩
- スタックトレース・DB エラーによるサーバ情報の露出
- **プラグイン**: `grep/error_pages`
- **スキャン種別**: パッシブ (grep)

### デフォルト認証情報
- デフォルトのユーザ名・パスワードが使われているかを確認
- **プラグイン**: `audit/http_auth_detect`, `audit/basic_auth`
- **スキャン種別**: アクティブ

## 認証・セッション管理

### ブルートフォース攻撃
- フォーム認証・HTTP 認証に対するパスワード総当たり
- **プラグイン**: `audit/form_auth`, `auth/generic`
- **スキャン種別**: アクティブ

### セッション管理の問題
- セッション ID の予測可能性・固定化の検出
- **プラグイン**: `grep/session_fixation`
- **スキャン種別**: パッシブ (grep)

### CSRF (クロスサイトリクエストフォージェリ)
- CSRF トークンの有無・有効性の確認
- **プラグイン**: `audit/csrf`
- **スキャン種別**: アクティブ

## XML / JSON 関連

### XXE (XML External Entity) インジェクション
- 外部エンティティを使ったファイル読み取りや SSRF
- **プラグイン**: `audit/xxe`
- **スキャン種別**: アクティブ

## サーバサイドリクエストフォージェリ (SSRF)

- サーバに内部ネットワークへのリクエストを送らせる
- **プラグイン**: `audit/ssrf`
- **スキャン種別**: アクティブ

---

## バッファオーバーフロー / フォーマット文字列

### バッファオーバーフロー
- 大量データ送信によるサーバの異常動作検出
- **プラグイン**: `audit/buffer_overflow`
- **スキャン種別**: アクティブ

### フォーマット文字列攻撃
- `%s`, `%x` などのフォーマット指定子の注入
- **プラグイン**: `audit/format_string`
- **スキャン種別**: アクティブ

---

## インフラ・サーバ情報収集

### サーババージョン情報の露出
- HTTP レスポンスヘッダからの Web サーバ・フレームワーク情報取得
- **プラグイン**: `infrastructure/server_header`, `grep/http_in_body`
- **スキャン種別**: パッシブ

### 既知の脆弱性を持つソフトウェアの検出
- 検出したバージョンを CVE データと照合
- **プラグイン**: `infrastructure/finger_apache`, `infrastructure/finger_iis`
- **スキャン種別**: パッシブ

### オープンリダイレクト
- パラメータを通じた外部サイトへのリダイレクト
- **プラグイン**: `audit/open_redirect`
- **スキャン種別**: アクティブ

## w3af では検出が難しい / できない脆弱性

| 脆弱性 | 理由 |
|--------|------|
| ビジネスロジックの欠陥 | 仕様の理解が必要で自動化が困難 |
| 認可の不備 (IDOR) | ユーザ間の権限比較が必要 |
| DOM ベース XSS (動的) | JavaScript エンジンの完全実行が困難 |
| レースコンディション | タイミング依存で再現が難しい |
| セキュリティログ・監視の失敗 | サーバ側の設定確認が必要 |
| 最新の CVE 対応 | メンテナンス低調により新しい脆弱性パターンへの対応が遅れる |

## プロファイル別の検査対象

| プロファイル | 主な検査項目 |
|------------|------------|
| `OWASP_TOP10` | OWASP Top 10 全般 |
| `fast_scan` | XSS, SQLi など高頻度の脆弱性に絞った高速スキャン |
| `full_audit` | 全プラグインを使った網羅的スキャン |
| `bruteforce` | 認証ブルートフォースに特化 |
| `web_infrastructure` | サーバ情報収集に特化 |
