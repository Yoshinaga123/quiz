# セキュリティツール比較: OWASP ZAP vs w3af vs Burp Suite

## 概要

| 項目 | OWASP ZAP | w3af | Burp Suite |
|------|-----------|------|------------|
| 開発元 | OWASP (オープンソース) | オープンソース | PortSwigger |
| ライセンス | Apache 2.0 (無料) | GPL v2 (無料) | Community (無料) / Professional・Enterprise (有料) |
| 主な用途 | Webアプリ脆弱性スキャン・プロキシ | Webアプリ脆弱性スキャン | Webアプリペネトレーションテスト・プロキシ |
| GUI | あり | あり (GTK) | あり |
| CLI | あり | あり | あり (Enterprise) |
| プラットフォーム | Windows / macOS / Linux | Linux (主に) | Windows / macOS / Linux |

---

## OWASP ZAP (Zed Attack Proxy)

- **特徴**: OWASP が管理するオープンソースの Web アプリケーションセキュリティスキャナ。初心者から上級者まで幅広く利用される。
- **強み**:
  - 完全無料・オープンソース
  - 自動スキャン・手動テストの両方に対応
  - REST API・CI/CD パイプライン連携が容易
  - 豊富なドキュメントとコミュニティ
  - Docker イメージが公式提供されている
- **弱み**:
  - Burp Suite と比べて手動テスト機能がやや劣る
  - プラグインの品質にばらつきがある
- **主な検出脆弱性**: SQL インジェクション、XSS、CSRF、セキュリティヘッダ不備など

---

## w3af (Web Application Attack and Audit Framework)

- **特徴**: Python 製のオープンソース Web アプリケーション脆弱性スキャナ。プラグインベースで拡張可能。
- **強み**:
  - 200 以上のプラグインによる広範な脆弱性検出
  - 完全無料・オープンソース
  - スクリプトで自動化しやすい
- **弱み**:
  - 現在はメンテナンスが低調で更新が少ない
  - GUI が古く使いにくい
  - Windows サポートが不安定
  - 最新の脆弱性への対応が遅れる場合がある
- **主な検出脆弱性**: SQL インジェクション、XSS、ファイルインクルード、コマンドインジェクションなど

---

## Burp Suite

- **特徴**: PortSwigger 社製の業界標準 Web アプリケーションセキュリティテストプラットフォーム。プロフェッショナル向けの機能が充実。
- **強み**:
  - 手動テスト機能が非常に強力 (Repeater、Intruder、Sequencer など)
  - 豊富な BApp Store 拡張機能
  - 直感的な UI と高い使いやすさ
  - 活発なアップデートと公式サポート
  - Burp Collaborator による帯域外 (OOB) 検出
- **弱み**:
  - Professional / Enterprise は有料 (高価)
  - Community 版は機能制限あり (スキャン自動化不可)
- **エディション**:
  - **Community**: 無料、基本的なプロキシ・手動テスト
  - **Professional**: 有料、自動スキャン・全機能
  - **Enterprise**: 有料、CI/CD 連携・大規模スキャン
- **主な検出脆弱性**: OWASP Top 10 全般、ビジネスロジック欠陥など

---

## 総合比較

| 観点 | OWASP ZAP | w3af | Burp Suite |
|------|-----------|------|------------|
| 無料で使えるか | ◎ 完全無料 | ◎ 完全無料 | △ Community は無料・機能制限あり |
| 自動スキャン精度 | ○ 良好 | ○ 良好 | ◎ 非常に高い (Pro) |
| 手動テスト機能 | ○ 良好 | △ 限定的 | ◎ 業界最高水準 |
| CI/CD 連携 | ◎ 容易 | ○ 可能 | ○ Enterprise で対応 |
| メンテナンス状況 | ◎ 活発 | △ 低調 | ◎ 活発 |
| 学習コスト | ○ 低〜中 | ○ 中 | ○ 中 |
| 日本語情報 | ○ 比較的多い | △ 少ない | ○ 比較的多い |

---

## 用途別推奨

- **コスト重視 / OSS のみ使いたい**: OWASP ZAP
- **CI/CD パイプラインへの組み込み**: OWASP ZAP (Docker 対応が充実)
- **本格的なペネトレーションテスト**: Burp Suite Professional
- **スクリプトで細かく自動化したい**: w3af (ただしメンテナンス状況に注意)
