# OWASP ZAP で検査できる脆弱性一覧

## 概要

OWASP ZAP はパッシブスキャン・アクティブスキャンの 2 種類のスキャンを組み合わせて脆弱性を検出します。

| スキャン種別 | 説明 | 対象サーバへの影響 |
|------------|------|-----------------|
| **パッシブスキャン** | 通信を観察するだけで検出 | なし (安全) |
| **アクティブスキャン** | 攻撃リクエストを実際に送信して検出 | あり (要許可) |

---

## OWASP Top 10 対応状況

| # | カテゴリ | ZAP での検出 |
|---|---------|------------|
| A01 | アクセス制御の不備 | ○ (一部) |
| A02 | 暗号化の失敗 | ○ |
| A03 | インジェクション | ◎ |
| A04 | 安全でない設計 | △ |
| A05 | セキュリティの設定ミス | ◎ |
| A06 | 脆弱なコンポーネント | △ |
| A07 | 認証・セッション管理の失敗 | ○ |
| A08 | ソフトウェアとデータの整合性の失敗 | △ |
| A09 | セキュリティログ・監視の失敗 | ✕ |
| A10 | サーバサイドリクエストフォージェリ (SSRF) | ○ |

## インジェクション系

### SQL インジェクション
- エラーベース / ブラインド / 時間ベース SQL インジェクション
- MySQL, PostgreSQL, MSSQL, Oracle など主要 DB に対応
- **スキャン種別**: アクティブ

### コマンドインジェクション (OS Command Injection)
- Unix / Windows コマンドの注入
- **スキャン種別**: アクティブ

### LDAP インジェクション
- LDAP クエリへの不正な文字列注入
- **スキャン種別**: アクティブ

### XPath インジェクション
- XML データを操作する XPath クエリへの注入
- **スキャン種別**: アクティブ

### Server-Side Template Injection (SSTI)
- Jinja2, Freemarker, Thymeleaf などのテンプレートエンジンへの注入
- **スキャン種別**: アクティブ

---

## クロスサイトスクリプティング (XSS)

### 反射型 XSS (Reflected XSS)
- URL パラメータやフォームの入力値がそのままレスポンスに反映される
- **スキャン種別**: アクティブ

### 格納型 XSS (Stored XSS)
- データベース等に保存されたスクリプトが後から実行される
- **スキャン種別**: アクティブ

### DOM ベース XSS
- クライアントサイドの JavaScript による XSS
- **スキャン種別**: アクティブ (Ajax Spider 併用推奨)

## セキュリティ設定ミス

### セキュリティヘッダの不備
| ヘッダ | 説明 |
|-------|------|
| `Content-Security-Policy` 未設定 | XSS 攻撃の緩和策が未設定 |
| `X-Frame-Options` 未設定 | クリックジャッキングのリスク |
| `X-Content-Type-Options` 未設定 | MIME スニッフィングのリスク |
| `Strict-Transport-Security` 未設定 | HTTPS 強制が未設定 |
| `Referrer-Policy` 未設定 | 参照元情報の漏洩リスク |
| `Permissions-Policy` 未設定 | ブラウザ機能の制限が未設定 |

- **スキャン種別**: パッシブ

### ディレクトリリスティング
- Web サーバのディレクトリ一覧が公開されている
- **スキャン種別**: アクティブ

### 管理画面・バックアップファイルの露出
- `/admin`, `/.git`, `/backup.zip` などの露出
- **スキャン種別**: アクティブ (Forced Browse)

---

## 認証・セッション管理

### セッション固定攻撃 (Session Fixation)
- ログイン前後でセッション ID が変わらない
- **スキャン種別**: アクティブ

### セッション ID のランダム性不足
- 推測可能なセッション ID の検出
- **スキャン種別**: パッシブ

### Cookie の属性不備
| 属性 | 問題 |
|------|------|
| `Secure` フラグなし | HTTP でもクッキーが送信される |
| `HttpOnly` フラグなし | JavaScript からクッキーにアクセス可能 |
| `SameSite` 未設定 | CSRF のリスク |

- **スキャン種別**: パッシブ

### CSRF (クロスサイトリクエストフォージェリ)
- CSRF トークンの有無を確認
- **スキャン種別**: アクティブ / パッシブ

---

## 暗号・通信の問題

### 弱い SSL/TLS 設定
- 古いプロトコル (SSL 3.0, TLS 1.0/1.1) の使用
- 脆弱な暗号スイートの使用
- **スキャン種別**: パッシブ

### 平文での機密情報送信
- HTTP (非 HTTPS) でのパスワード・クレジットカード情報の送信
- **スキャン種別**: パッシブ

### 情報漏洩
- レスポンスヘッダやエラーメッセージによるサーバ情報 (バージョン等) の露出
- **スキャン種別**: パッシブ

---

## ファイル・パス操作

### パストラバーサル (Directory Traversal)
- `../` を使ってサーバ上の任意ファイルを読み取る
- **スキャン種別**: アクティブ

### リモートファイルインクルード (RFI) / ローカルファイルインクルード (LFI)
- 外部・内部のファイルをインクルードさせる攻撃
- **スキャン種別**: アクティブ

---

## サーバサイドリクエストフォージェリ (SSRF)

- サーバに内部ネットワークへのリクエストを行わせる
- Burp Collaborator 相当の Out-of-Band 検出は ZAP Callback も対応
- **スキャン種別**: アクティブ

---

## XML / JSON 関連

### XXE (XML External Entity) インジェクション
- 外部エンティティを使ったファイル読み取りや SSRF
- **スキャン種別**: アクティブ

### JSON インジェクション
- JSON パラメータへの不正な値注入
- **スキャン種別**: アクティブ

---

## その他

### オープンリダイレクト
- 外部の悪意あるサイトへのリダイレクト
- **スキャン種別**: アクティブ

### HTTP レスポンス分割 (CRLF インジェクション)
- レスポンスヘッダへの改行文字の注入
- **スキャン種別**: アクティブ

### クリックジャッキング
- iframe で UI を重ねてクリックを誘導する攻撃
- **スキャン種別**: パッシブ (`X-Frame-Options` の確認)

### 外部リダイレクト
- パラメータを通じた外部サイトへのリダイレクト
- **スキャン種別**: アクティブ

---

## ZAP では検出が難しい / できない脆弱性

| 脆弱性 | 理由 |
|--------|------|
| ビジネスロジックの欠陥 | 仕様の理解が必要で自動化が困難 |
| 認可の不備 (IDOR) | ユーザ間の権限比較が必要 |
| レースコンディション | タイミング依存で再現が難しい |
| サプライチェーン攻撃 | 依存ライブラリの静的解析が必要 |
| セキュリティログ・監視の失敗 | サーバ側の設定確認が必要 |

これらは手動テストや他のツール (Burp Suite、SAST ツールなど) との組み合わせで補完することを推奨します。
